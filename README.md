# Шахтар — таймер до наступного матчу

Страница для телевизоров: показывает обратный отсчёт до ближайшего матча ФК «Шахтар».
Данные (команды, логотипы, лига, дата и время) парсятся с официального сайта клуба
[shakhtar.com](https://shakhtar.com/uk-ua/matchday/fixtures/). Вёрстка 1280×1027 автоматически
масштабируется под любую диагональ экрана.

## Как это работает

- `index.html` — сама страница с таймером.
- `scrape.js` — парсер страницы расписания shakhtar.com.
- `update.js` — запускает парсер и сохраняет `match.json` и логотипы команд в `logos/`.
- `.github/workflows/update.yml` — GitHub Actions: раз в 30 минут запускает `update.js`
  и коммитит изменения (только если сменился матч).
- `server.js` — необязательный локальный сервер (см. ниже).

Браузер не может читать shakhtar.com напрямую (CORS), поэтому данные собирает Actions
и кладёт в `match.json`, а страница читает этот файл.

## Запуск из GitHub (для телевизора)

1. Включить GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
2. Через 1–2 минуты страница будет доступна по адресу `https://barnibeats.github.io/Shahtar/`.
   Эту ссылку вставьте в браузер телевизора.
3. Открыть вкладку **Actions** и один раз запустить «Update match data» кнопкой **Run workflow**.
   Если GitHub просит разрешить запись: **Settings → Actions → General → Workflow permissions →
   Read and write permissions**.

Заметки:
- Данные могут отставать от сайта клуба на 30–60 минут (GitHub не гарантирует точное время cron).
  На сам таймер это не влияет — он считается на телевизоре по времени матча.
- После матча сайт клуба переключится на следующий, и страница подхватит его при очередном обновлении.
- Телевизору нужен интернет (шрифты подгружаются из Google Fonts).
- Если репозиторий приватный, Pages на бесплатном тарифе может быть недоступен — сделайте репозиторий публичным.

## Локальный запуск

Нужен Node.js 18+.

```
node server.js
```

Откройте http://localhost:3000. Сервер сам парсит сайт клуба (кэш 5 минут), `match.json` не нужен.

Обновить `match.json` вручную:

```
node update.js
```
